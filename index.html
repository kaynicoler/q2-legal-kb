Manage Knowledge Base Content
Edit sections, subtopics, articles, and bookmarks as JSON. Changes save in this browser via localStorage. Use Export to download a portable backup, then Import JSON later to restore those changes in this or another browser. You can delete articles directly from article cards, from the open article toolbar, or from Quick Edit. Use the Up/Down buttons on page cards and article cards to reorder without editing JSON.
How to add content: add a section, category, or article object below. Article fields are id, section, category, title, type, owner, updated, summary, and content. Bookmark cards can use type: "Bookmark" and HTML links in content. PDFs imported with the top-bar Import PDF button are converted into editable article objects and saved here.
